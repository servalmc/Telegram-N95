# История версий

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

Каждая версия помечается тегом `vX.Y.Z`. Номер в `inc/SymgramVersion.h`,
`sis/Symgram.pkg` и строке «О программе» должен совпадать.

## [0.2.23] — 2026-08-30

### Исправлено
- Личные чаты слоя 158 приходят как `user#3ff6ecb0` (без `flags2`); клиент
  их не узнавал, в списке оставались только несколько последних диалогов.

## [0.2.22] — 2026-08-30

### Исправлено
- Список диалогов слоя 158 приходит как `dialog#a8edd0f5`; клиент его не
  узнавал, кэш не обновлялся, группы оставались без названий.

## [0.2.21] — 2026-08-30

### Исправлено
- На вложенных экранах (чат, настройки, обновление, контакты) правая
  софт-клавиша — «Назад», а не «Выход».

## [0.2.20] — 2026-08-30

### Исправлено
- Проверка обновлений больше не роняет приложение: второй `RConnection`
  поверх уже открытого IAP Telegram на S60 3rd FP1 вызывал панику.
- «Установить» запускает системный установщик и закрывает Symgram, чтобы
  пакет можно было поставить поверх без аварийного завершения.

## [0.2.19] — 2026-08-29

### Добавлено
- Экран обновления в настройках: «Проверить» спрашивает GitHub, «Установить»
  ставит `.sisx` с диска после подтверждения.

### Исправлено
- В чате с тысячами непрочитанных запрашиваются только последние 50
  сообщений, серверу уходит `readHistory` / `channels.readHistory`.

## [0.2.18] — 2026-08-29

### Добавлено
- Полуавтоматическое обновление через GitHub: репозиторий публичный,
  `.sisx` выкладывается релизом `vX.Y.Z`, на телефоне пункт «Обновление»
  спрашивает GitHub и ставит пакет с карты / из `C:\Data\Symgram`, если
  он уже скачан (N95 не умеет TLS 1.2, поэтому файл с GitHub качается
  на компьютере).
- `tools\publish-release.bat` создаёт GitHub Release из `sis\Symgram.sisx`.
- `api_id` / `api_hash` живут в gitignored `inc/SymgramApiLocal.h`.

## [0.2.17] — 2026-08-29

### Исправлено
- Обновление без удаления: все `.sisx` подписываются одним сертификатом
  `sis/selfsign.*` (он в git). Телефон ставит пакет поверх, `session.bin`
  в приватном каталоге не трогается, повторный вход в Telegram не нужен.
- Копия сессии пишется в `C:\Data\Symgram\session.bin`, чтобы вход
  восстановился даже после удаления приложения.

## [0.2.16] — 2026-08-29

### Изменено
- Шрифт текста в открытом чате увеличен в 2,5 раза.
- Эмодзи рисуются картинками Twemoji 64×64 с мягкой альфа-маской, а не
  геометрией; в пакет входит `Symgram_emoji.mbm`.

## [0.2.15] — 2026-08-29

### Исправлено
- Вылет в чате с длинной перепиской: gzip больше не рвёт сессию, векторы TL
  ограничены (иначе разбор крутился до сторожевого таймера), сервисные
  сообщения и хвост `message` пропускаются целиком, история запрашивается
  по 8 сообщений, буфер превью убран со стека.

## [0.2.14] — 2026-08-29

### Исправлено
- Остальные группы без вкладки: имена ищутся по всему ответу, а не цепочкой
  до первого сбоя; список диалогов не обрывается на черновике; подгружаются
  следующие страницы (до 90 диалогов).

## [0.2.13] — 2026-08-29

### Исправлено
- Группы без названия во вкладке «Чаты»: черновик в диалоге сбивал разбор
  следующих пиров, а архивная папка обрывала список. Хвост `chat`/`channel`
  больше не ищется по случайным 4 байтам — из‑за этого имена обрывались
  после двух групп.

## [0.2.12] — 2026-08-28

Рабочий клиент на Nokia N95 8GB: вход, список диалогов, переписка, вложения.

### Добавлено
- Авторизация: номер, код из SMS / Telegram, облачный пароль (2FA).
- Сохранение сессии (`session.bin`); повторный вход не требуется.
- Список чатов с превью; вкладки **Чаты** / **Группы** / **Каналы**.
- Контакты и настройки в меню «Опции» (не отдельными вкладками).
- Отправка текста, эмодзи, фото и файлов; открытие и сохранение вложений.
- Кэш диалогов, контактов и истории в приватном каталоге.
- Разбор `FLOOD_WAIT_N`: на экране «Ждите Nh Nm», автоповтор RPC отключён.

### Исправлено
- Группы и каналы без названия и с `PEER_ID_INVALID`: имена сопоставляются
  по типу пира, не только по id; супергруппы (megagroup) как kind 4.
- Запуск 0.2.10: урезан разбор хвоста `chat`/`channel`, чтобы не раздувать стек.
- Модальные окна из `RunL` после входа больше не вешают UI.

### Ограничения
- Самоподписанный `.sisx` поверх старой установки часто оставляет мёртвый exe —
  сначала удалите предыдущую версию.
- Нет поиска, архива, видео, голосовых, реакций, секретных чатов и фоновых
  уведомлений.
- Картинки в README — макеты `tools\preview-ui.ps1`, не фотографии устройства.

пакет `req_pq_multi`. Сборка GCCE и самоподписанный `.sisx`.
