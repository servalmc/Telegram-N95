# Установка на Nokia N95 8GB

Референсное устройство из ТЗ. Пакет самоподписанный, поэтому телефон по умолчанию
откажется его ставить — нужны две настройки.

## Подготовка телефона

Оба параметра лежат в `Меню → Средства → Диспетчер прил.` → `Параметры` → `Настройки`:

| Параметр | Значение | Зачем |
| --- | --- | --- |
| Установка ПО | Все | иначе принимаются только пакеты Symbian Signed |
| Проверка сертиф. в сети | Выкл. | иначе телефон пойдёт проверять отзыв сертификата и откажет |

Без первого пункта установка обрывается с сообщением о недействительном сертификате,
без второго — с ошибкой проверки сертификата, даже когда сеть доступна.

## Сборка и установка

```
tools\release.bat
```

Скрипт собирает GCCE release и кладёт готовый `sis\Symgram.sisx`. Дальше файл нужно
передать на телефон любым способом — Bluetooth, кабель через Nokia PC Suite или карта
памяти — и открыть на устройстве. С GitHub удобнее класть файл в `C:\Data\Symgram\`
или в корень карты как `Symgram-X.Y.Z.sisx` и откройте **Настройки → Обновление**.
«Проверить» спрашивает GitHub, «Установить» запускает пакет с диска.

**Не удаляйте** установленный Symgram перед обновлением. Закройте приложение и
ставьте новый `.sisx` поверх: пакеты подписаны одним сертификатом
(`sis/selfsign.cer` в репозитории), поэтому установщик заменяет exe и оставляет
приватный каталог с `session.bin`. Удаление как раз и заставляет входить заново
и ловить `FLOOD_WAIT` у Telegram.

Если приложение всё же сняли, начиная с 0.2.17 вход восстанавливается из
`C:\Data\Symgram\session.bin`.

При установке телефон спросит подтверждение прав: доступ к сети, чтению и записи
пользовательских данных и к окружению. Это те самые `NetworkServices`, `ReadUserData`,
`WriteUserData` и `UserEnvironment` из `.mmp`; все они выдаются пользователем,
поэтому Symbian Signed не нужен.

## Если приложение не появилось в меню

Проверить, что установился регистрационный ресурс
`\private\10003a3f\import\apps\Symgram_reg.rsc`. Именно по нему система показывает
приложение в меню; при его отсутствии исполняемый файл ставится, но иконки и пункта
меню не будет.

## Диагностика падений

По умолчанию приложение при панике просто закрывается, без сообщения. Чтобы телефон
показывал код паники, нужно создать пустой файл `errrd` без расширения в каталоге
`C:\resource\`. Для этого требуется файловый менеджер с доступом к системным папкам.
